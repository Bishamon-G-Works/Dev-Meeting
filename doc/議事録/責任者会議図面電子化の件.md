# 責任者会議 たたき台資料

## 製作図面の電子化について（議論用）

**目的**：図面の電子化を進めるべきか、現場運用・品質保証を踏まえて方向性を議論する。

---

## 1. 背景

現在の製作図面は、検図・承認・保管まで紙を中心に運用している。

一方で、図面検索性や保管スペース、設計変更時の最新版管理などを考えると、電子化の必要性が高まっている。

今回の議論では、「紙を無くす」ことではなく、**品質を維持しながら正式図面を電子化として運用できるか** を検討したい。

---

## 2. 現状と電子化イメージ

### 現状
CAD作図 → 紙で検図・赤入れ → 承認 → 紙保管 → 製造

### 電子化案
CAD作図 → **紙で検図・赤入れ** → CAD修正 → 電子承認 → **PDFを正式図面として保管** → 製造（電子閲覧・必要時印刷）

**ポイント**

- 検図は従来どおり紙を活用
- 正式図面は電子（PDF）を正本とする
- 紙は検図用の作業媒体であり、正式版ではない

---

## 3. 紙と電子の比較

| 項目 | 紙図面 | 電子図面 |
|------|---------|----------|
| 検図のしやすさ | ◎ 全体を見渡せる | △ モニターに依存 |
| 赤入れ | ◎ 直感的 | ○ 注釈機能が必要 |
| 最新版管理 | △ 回収漏れの恐れ | ◎ 一元管理しやすい |
| 検索性 | × 手作業 | ◎ 品番検索可能 |
| 保管スペース | × 必要 | ◎ サーバ保管 |
| 改訂履歴 | ○ 原本管理 | ◎ 履歴管理しやすい |

### まとめ

- **検図工程は紙が優位**
- **保管・版管理は電子が優位**

---

## 4. 最大の課題

### 紙と電子の不一致

電子化で最も重要な課題は、紙と電子の二重管理による最新版管理である。

#### 想定リスク

1. 紙に赤入れした内容がCADへ反映されない
2. PDFを再発行せず旧版が正式図面になる
3. 古い紙図面が現場に残る
4. CAD・紙・PDFの内容が一致しない

> **課題：紙と電子の不一致を防ぐ運用ルールがなければ、最新版管理は成立しない。**

---

## 5. 必要な運用ルール

| ルール | 目的 |
|---------|------|
| 正本はPDFと定義 | 正式図面を一本化 |
| 紙は検図専用 | 作業媒体と位置付ける |
| 修正後にPDF発行 | 赤入れ反映漏れ防止 |
| 電子承認を実施 | 承認履歴を残す |
| 旧版は閲覧制限 | 誤製作防止 |

---

## 6. 責任者会議で決めたい事項

### 議題① 正式図面の定義
- 電子PDFを正本とするか

### 議題② 検図方法
- 紙検図を継続するか

### 議題③ 最新版管理
- 紙検図から電子正本へ移行する確認プロセスを設けるか

### 議題④ 製造現場運用
- 電子閲覧を基本とし、必要時のみ印刷とするか

---

## たたき台結論

検図品質を維持するため紙検図は継続し、正式図面の保管・版管理は電子へ移行する方向で検討したい。

その前提として、電子を唯一の正本とし、紙と電子の不一致を防ぐ運用ルールの整備が必要である。
