# 責任者会議 たたき台資料

## 製作図面の電子化について（議論用）

**目的**：図面の電子化を進めるべきか、現場運用・品質保証を踏まえて方向性を議論する。

---

## 1. 背景

ASC40・NSA40の量産試作図面を山崎部長に検図いただいた際、AI検図を行うために図面データの提出を求められた。

その時、紙図面を印刷して検図し保管するという今の運用を見て、「そもそも製作図面は紙で持ち続ける必要があるのか」という話になった。

確かに、図面は年々増え続けて保管場所も圧迫している。スキャンした図面は文字がつぶれて見づらくなることも多く、紙を出力・保管するコストも掛かる。

一方で、工場ではDocuWorksで図面を見ることも当たり前になってきており、以前より電子図面を使う環境は整ってきている。

武村自身もこのタイミングで「検図は紙、原図の保管は電子化」という運用が現実的にできないか、一度議論する価値があると感じた。

今回の議論では、「紙を無くす」ことではなく、**品質を維持しながら正式図面を電子化として運用できるか** を検討したい。

---

## 2. 現状と電子化イメージ

### 現状
CAD作図 → 紙で検図・ペン入れ → CAD修正　→ 紙で承認 → 紙保管 → ドキュワークス電子化＆紙図面出力 → 製造（電子閲覧・必要時印刷）


### 電子化案
CAD作図 → 紙で検図・ペン入れ → CAD修正 → 電子承認 → PDFまたはXDWを正式図面として保管 → 製造（電子閲覧・必要時印刷）

**ポイント**

- 検図は従来どおり紙を活用
- 正式図面は電子（PDFまたはXDW）を原図とする
- 紙は検図用の作業媒体であり、正式版ではない

---

## 3. 紙と電子の比較

| 項目 | 紙図面 | 電子図面 |
|------|---------|----------|
| 検図のしやすさ | ◎ 全体を見渡せる | △ モニターに依存 |
| ペン入れ | ◎ 直感的 | ○ 注釈機能が必要 |
| 最新版管理 | △ 回収漏れの恐れ | ◎ 一元管理しやすい |
| 検索性 | × 手作業 | ◎ 品番検索可能 |
| 保管スペース | × 必要 | ◎ サーバ保管 |
| 改訂履歴 | ○ 原本管理 | ◎ 履歴管理しやすい |

### まとめ

- **検図工程は紙が優位**
- **保管・版管理は電子が優位**

---

## 4. 最大の課題

### 紙と電子の不一致

電子化で最も重要な課題は、紙と電子の二重管理による最新版管理である。

#### 想定リスク

1. 紙にペン入れした内容がCADへ反映されない
2. CADは修正したのに、正式PDFまたはXDWを更新し忘れる
3. 古い紙図面が現場に残る
4. CAD・紙・PDFまたはXDWの内容が一致しない

> **課題：紙と電子の不一致を防ぐ運用ルールがなければ、最新版管理は成立しない。**

---

## 5. 必要な運用ルール

| ルール | 目的 |
|---------|------|
| 原図はPDFまたはXDWと定義 | 正式図面を一本化 |
| 紙は検図専用 | 作業媒体と位置付ける |
| 修正後にPDFまたはXDW出力 | ペン入れ反映漏れ防止 |
| 電子承認を実施 | 承認履歴を残す |
| 旧版は閲覧制限 | 誤製作防止 |

---

## 6. 責任者会議で決めたい事項

### 議題① 正式図面の定義
- 電子PDFまたはXDWを原図とするか

### 議題② 検図方法
- 紙検図を継続するか

### 議題③ 最新版管理
- 紙検図でペン入れした内容を、CAD原図・正式PDFまたはXDWへ確実に反映させる確認工程を設けるか。

### 議題④ 製造現場運用
- 電子閲覧を基本とし、必要時のみ印刷とするか
